# FPVS Studio

FPVS Studio is a Windows desktop app for creating and running Fast Periodic
Visual Stimulation (FPVS) experiments without writing code.

The app guides you through the main study setup:

- create a project in your FPVS Studio Root Folder
- add image or word conditions
- choose base and oddball stimuli
- assign condition trigger codes
- set display, session, fixation, and response options
- launch fullscreen participant sessions
- save run logs and participant summaries with the project

New FPVS-Oddball projects default to a 6 Hz base rate with an oddball every fifth
stimulus (1.2 Hz). You can change the presentation frequency and oddball spacing
to match your protocol and display. See [Run a Session](run-session.md#recording-setup)
for EEG recording options.

## Start Here

- [Install FPVS Studio](install.md) on the lab computer.
